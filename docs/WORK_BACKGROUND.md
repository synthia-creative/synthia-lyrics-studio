# 作業用背景とSRT読み込み（SYNTHIA v0.2.0）

## 作業用背景

「曲とタイミング」の下で画像・動画を選択すると、現在のリリックモーションと重ねて確認できます。
対応はブラウザがデコードできる画像・動画です。PNG、JPG、MP4、WebMはChrome・Edgeで確認しました。

- 表示: 背景＋リリック / 通常表示
- フィット: 全体表示（contain） / 画面いっぱい（cover）
- 背景不透明度: 0〜100%
- 動画は音声なしで、現在時刻・再生・停止・シーク・タップ同期の速度に連動
- 通常再生は150msを超えるずれを補正。停止・スクラブは0.5msを超えるずれを補正
- 動画終了後は最後のフレームを保持。アプリのループで先頭へ戻ると動画も戻る

画像・動画は`URL.createObjectURL(file)`でローカル保持します。サーバー送信、IndexedDBへの背景保存、JSONへのファイル本体・blob URL・ファイル名の保存は行いません。
解除・差し替え・読み込み失敗・新しいプロジェクトの読み込み・初期化・ページ離脱時にURLを破棄します。読み込み中の差し替えも世代番号とキャンセル処理で管理します。

## 保存・復元

JSONには次の設定だけを追加します。既存の`version: 1`、歌詞、音源、演出、タイミングの形式は維持します。

```json
"workBackground": {
  "enabled": true,
  "fit": "contain",
  "opacity": 1
}
```

プロジェクトの再読み込みやページ再表示時は「作業用背景を再選択してください」と案内します。
背景を付けたままでも、通常MP4・PNGには背景を含めません。通常表示では元のRenderer呼び出しを使用します。

## 描画の境界

プレビューの背景→別Canvasに既存Rendererで描いた透明リリック→プレビュー専用ガイドの順で合成します。
エクスポート処理（src/11_export.js）とRenderer本体（src/09_render.js）は変更しません。
不透明な帯やパネルを描く演出は背景を覆うことがあります。元のモーション・図形を維持するため、こうしたパネルを自動的に消したり透明化したりしません。

## SRT読み込み

歌詞欄の「SRTを読み込む」からUTF-8のSRTを選択します。BOM・CRLF、カンマまたは小数点のミリ秒表記に対応します。
検証と置き換え確認の後、字幕ごとに1フレーズとして読み込みます。字幕内の改行はスペースにまとめ、b/i/u/fontタグは書式を取り除きます。
歌詞の`/`、`*`、`|`、`!`はSRTモードでそのままの文字として扱います。

開始時刻はミリ秒精度のLRCタグへ、終了時刻は`timing.lineEnds`へ保存します。`timing.source: "srt"`の場合だけ終了時刻を適用し、文字整列の先行表示を適用しません。
手動で開始時刻を変更すると、その指定が優先されます。歌詞を直接編集するかLRCを読み込むとSRT終了時刻の指定を解除し、既存のタイミング動作へ戻ります。「元に戻す」はSRTの時刻指定も復元します。

対応対象は時刻順で重ならない字幕です。重複、終了が開始以前、不正な時刻、空字幕、近すぎる開始時刻（50ms未満）は読み込み前に拒否し、現在の歌詞を維持します。
原版JIZURAはSRT終了時刻拡張を解釈しません。既存JIZURA/LRCプロジェクトの読み込み・計画結果は維持しています。
