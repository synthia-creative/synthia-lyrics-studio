# 背景込み完成MP4（SYNTHIA v0.3.0）

「リリックのみMP4」と「完成動画MP4」を別々に書き出せます。通常MP4・通常PNGには読み込んだ素材背景を含めません。

## 使い方

1. 楽曲と歌詞（SRTまたはLRC）を読み込みます。
2. 「作業用背景」で静止画または動画を選択します。
3. フィット、拡大率、X/Y、不透明度、開始位置、終了後の動作を設定します。
4. 書き出し欄で画面比・解像度・fps・画質・音声の有無・行範囲を選びます。
5. 「完成動画MP4を書き出す」を押します。長い動画は「完成動画（ファイルに直接保存）」を利用できます。

楽曲を読み込まない場合は無音です。保存済みプロジェクトが楽曲名を持つのに音源を復元できていない場合は、再読み込みを求めて停止します。背景動画内の音声は使用しません。

プロジェクト名が「正解ごっこ」なら「正解ごっこ.mp4」です。未入力の場合は「SYNTHIA.mp4」です。新しい完成動画のファイル名にはJIZURAの既定名や行範囲の接尾辞を追加しません。

## 背景設定

| 設定 | 動作 |
|---|---|
| Cover / Contain | 初期値はCover。素材の縦横比を保って画面を覆うか、全体を表示します |
| 拡大率 | 初期値100%。フィット後の大きさに対する10〜1000% |
| X / Y位置 | 初期値0%。画面の幅・高さに対する移動量。正のXは右、正のYは下 |
| 不透明度 | 初期値100%。0%なら素材背景を描かず、土台は黒 |
| 背景素材開始位置 | 初期値0秒。素材の読み出しを開始する位置 |
| タイムライン開始位置 | 初期値0秒。この時刻より前は背景を黒にします |
| 最終フレーム保持 | 初期値。映像トラックの最終PTSのフレームを保持 |
| ループ | 素材開始位置から映像トラックの末尾までを繰り返します |
| 黒背景 | 映像トラック終了後は黒にします |

静止画にはタイムライン開始位置、フィット、拡大率、X/Y、不透明度を適用します。静止画の素材開始位置と終了後の動作は表示に影響しません。

「通常表示」はプレビューの切り替えです。背景が選択されていれば、通常表示中でも完成MP4には選択した背景を含めます。完成MP4に含めたくない場合はリリックのみMP4を使います。

## 時刻とレンダリング

各出力フレームの時刻は、必ず `t = exportStart + frameIndex / fps` で計算します。
動画背景の素材時刻は `t - timelineStart + mediaStart` です。音源・SRT・モーションも同じタイムライン時刻を参照します。

出力は別Canvasへの背景描画、既存Rendererの透明リリック（タイトル・HUDを含む）、VideoFrame、H.264エンコードの順です。プレビュー専用ガイドは含めません。MediaRecorderやプレビューCanvasの録画は使いません。

画像は直接drawImageします。動画はローカルのMediabunny 1.61.1で表示時刻（PTS）に対応するフレームを取得します。HTMLVideoElementのシークは完成MP4に使いません。VFR、Bフレーム、映像トラックの正の開始PTSにも対応します。背景の長さは音声を含むファイル全体の公称尺ではなく、映像トラックの最終フレームの終了PTSです。

プレビューにはHTMLVideoElementを使い、同じ開始位置・終了処理・映像トラックの長さを適用します。再生中の時計差は150ms以上で補正し、停止・スクラブは正確な時刻へシークします。

SRTの開始・終了時刻やLRCの時刻は変更しません。既存の行範囲に付く前後の余白も維持します。出力の長さはフレーム境界へ切り上げ、範囲を超える端数の音声は無音で埋めます。

楽曲はWebCodecs AudioEncoderによるAAC、MP4の多重化は既存のmp4-muxerです。非対応時は理由を表示し、完成MP4でVP9/Opusや無音への自動切り替えは行いません。長尺の音声処理は20秒単位で行い、サンプル位置から時刻を計算します。

## 保存とローカル素材

画像・動画はブラウザ内のFile/blob URLとして扱い、サーバーへ送信しません。素材本体・ファイル名・blob URLはプロジェクトJSONや背景用IndexedDBへ保存しません。
`workBackground`に表示・フィット・不透明度・拡大率・位置・開始位置・終了処理だけを保存します。既存v0.2.0の設定も読み込めます。
プロジェクトを開き直した場合は素材を再選択してください。解除・差し替え・ページ離脱時はURLを破棄します。

既存のリリック単体MP4、PNG、SRT/LRCのタイミング、Renderer、プロジェクトversion、JIZURAのMIT表示は維持しています。
背景を覆う不透明な帯・パネルなどの既存演出はそのまま描きます。追加のオーバーレイ編集機能はこの版では追加していません。

## 検証と範囲

2026-10-04、合成素材を用いてChrome・Edgeで確認しました。実際の楽曲や利用者のMV素材は使っていません。

- PNG/JPG/WebP、MP4/WebM、Cover/Contain、拡大・位置・不透明度・素材開始/配置開始、hold/loop/black
- 16:9、9:16、1:1、30fps/60fps、1080p、4K短尺
- VFR、Bフレーム、正のPTS、音声が映像より長い背景、7言語の依存読込と終了処理
- Chrome・Edgeで5分1080p30fpsの全9000フレームを検査。出力時計の累積誤差0、25fps背景のフレーム選択差は最大約33.3ms（元動画のフレーム間隔以内）
- 実MP4から音声をデコードし、0.5/149.5/299.5秒の確認音はすべて約0.104msの差。累積ずれなし。SRTと映像の確認マーカーも照合
- 範囲MP4と直接保存MP4の楽曲・字幕・背景時刻を確認。背景動画の880Hz音声が入らず、楽曲の440Hz音声だけが出力されることを確認
- GPUを無効にした検査で、30フレームの描画入力SHA-256が再出力でも一致。Canvas録画とHTML動画シークを禁止した状態でも完成MP4を出力
- キャンセル、エンコーダー解放、書き出し中の設定固定、JSON保存・復元、390px/1440pxの画面確認
- 既存の音源・LRC・保存・MP4・PNG・画面サイズの回帰22項目

確認用動画がH.264、音声がAACであること、寸法・fps・フレーム数もffprobeで検査しました。
スマホ実機、Safari/Firefox、5分を超える長尺、長尺4K、全コーデック・全演出の組み合わせは未確認です。MP4バイトの完全一致は主張しません。
